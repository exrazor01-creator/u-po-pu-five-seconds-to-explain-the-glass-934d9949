Five Seconds to Explain the Glass — a tiny pure-stdlib Python program that writes the one sentence a house cat would say in its own defence after knocking a glass off the table, to /output/entry.txt.

## The entry

> It was blocking my view of the bird, and frankly the crash was the most interesting thing this windowsill has produced all week.

128 characters — inside the 1–200 gate. No apology, no gravity, no slippery edge: the cat had a reason (the bird), a motive (the view) and a verdict (the crash improved the week). Pure cat logic, delivered in five seconds flat.

## Run it

```sh
python3 main.py
```
